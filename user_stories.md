# User Stories - Smart Clinic Management System

## Admin
- As an Admin, I want to log in to the admin portal securely using my credentials so that I can manage system operations.
- As an Admin, I want to add new doctors to the system with their specialty and contact details.

## Doctor
- As a Doctor, I want to view a list of all my patient appointments so that I can plan my daily schedule.
- As a Doctor, I want to manage prescriptions for my patients.

## Patient
- As a Patient, I want to search and find a doctor by name or specialty so that I can book an appointment.
- As a Patient, I want to view all my booked appointments using my login credentials.
